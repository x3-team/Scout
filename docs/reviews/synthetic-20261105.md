## Повторение

Python 3.12/3.13, из Scout: установить requirements-vision.txt, затем python scripts/check_synthetic_vision.py --output-dir runs/vision/stress. Каталог должен быть новым. CLI возвращает 1 при любом несовпадении ожидания или повторного результата; все результаты сохраняются до выхода. CI артефакт включает полную матрицу.

В первой локальной установке OpenCV аварийно завершался при импорте (SIGBUS); повторная установка того же закреплённого wheel в отдельное окружение дала рабочий import. Этот неисполненный запуск не считался успешным тестом. Результаты выше получены после восстановления среды.

## Ограничения

Синтетика проверяет регрессии программы и заданные сочетания искажений. Она не измеряет точность на фотографиях, не обучает модель и не закрывает ручной Gate1/SCOUT-02. Реальные фото, отдельная evaluation выборка и ручной Windows-путь остаются следующими проверками. Нельзя переносить проценты прохождения этой матрицы на склад/камеру/железо. Текущий CI и повтор full-route фиксируются в PR после выполнения.
