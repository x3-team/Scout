# JSON отчёт SCOUT-01

Версия контракта — schema_version: "1.0". В документе нет случайного UUID,
абсолютных путей и времени компьютера, поэтому файлы можно воспроизводимо сравнивать.

| Поле | Значение |
| --- | --- |
| scout_version | Версия реализации |
| scenario, scenario_sha256, seed | Название и воспроизводимые входы |
| execution, clock | digital_simulation, simulation_seconds |
| evidence | source: scenario_fixture, synthetic: true, computer_vision_executed: false |
| status, reason | Терминальный исход и конкретная причина |
| visited_stations | Посещённые ID в порядке посещения |
| planned_stations | Три запланированные точки |
| returned_home, stopped | Возврат и подтверждённая нулевая скорость в модели |
| metrics | Длительность, длина, посещения, изменения, запас хода, шаги и защита |
| inspections | Только выполненные инспекции с временем, ID, результатом и источником |
| events | Последовательность событий с модельным временем |
| trace | Разреженная траектория, включая последнюю позу |
| final_pose | X и Y в метрах, heading в радианах |
| world | Полная нормализованная конфигурация |
| limitations | Ограничения интерпретации |

## Исходы

| Статус | Причина | Семантика |
| --- | --- | --- |
| COMPLETED | ROUTE_FINISHED | Все три точки посещены, робот вернулся домой |
| BLOCKED | PATH_BLOCKED | Недостаточный запас хода, движение прекращено |
| FAULT | SENSOR_UNAVAILABLE | Нет датчика, NaN, бесконечность или отрицательная дальность |
| FAULT | STALE_SENSOR | Просроченная или будущая временная метка |
| FAULT | LOCALIZATION_UNAVAILABLE | Некорректная поза |
| FAULT | FOOTPRINT_GUARD | Защита отклонила пересекающее движение |
| FAULT | STOP_NOT_CONFIRMED | Адаптер не подтвердил остановку |
| TIMEOUT | MISSION_TIMEOUT | Превышен лимит модельного времени |

completion_ratio — число посещённых точек / 3. Даже при значении 1 обход может
не завершиться, если робот не вернулся на старт. changed_station_count считает
изменённые точки, а не отдельные отклонения.

min_front_clearance_m включает шум и ограничение дальности датчика.
Это минимальный наблюдаемый запас хода, а не расстояние между всеми поверхностями.
control_steps — число выполненных модельных шагов.

CHANGED и UNCHANGED получаются из подготовленных данных. Тип результата резервирует
INCONCLUSIVE для расширения; это не «норма» и не результат настоящего зрения.
